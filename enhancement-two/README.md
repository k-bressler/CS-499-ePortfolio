# Enhancement Two: Algorithms and Data Structures

## Artifact
**CS 340 – Animal Shelter Dashboard**

## Enhancement Overview

For this enhancement, I expanded the Animal Shelter Dashboard by implementing advanced search and filtering functionality. Users can search animal records using multiple criteria, including animal type, breed, sex, and age range.

The enhancement also includes ascending and descending sorting options and a reset feature to clear search criteria.

These improvements demonstrate the application of algorithms, dynamic database queries, data filtering, and user-centered design to improve data retrieval and usability.
