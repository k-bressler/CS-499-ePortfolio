# Enhancement One: Software Engineering and Design

## Artifact
**CS 340 – Animal Shelter Dashboard**

This artifact is an animal shelter dashboard originally developed in CS 340. The application uses Python, Dash, and MongoDB to display and manage animal shelter data.

## Enhancement Overview

For the Software Engineering and Design enhancement, I expanded the original dashboard by creating an animal management interface. The enhanced application allows users to add, edit, view, and delete animal records through the dashboard interface.

This enhancement demonstrates improvements in software design, usability, CRUD functionality, input validation, error handling, and integration between the application's user interface and MongoDB database.
