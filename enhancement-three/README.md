# Enhancement Three: Databases

## Artifact
**CS 340 – Animal Shelter Dashboard**

## Enhancement Overview

For this enhancement, I improved the database functionality of the Animal Shelter Dashboard by implementing MongoDB schema validation, improved error handling, and completed additional testing.

The schema validation enforces required fields, acceptable data types, and restrictions on invalid values. These improvements strengthen data integrity by preventing invalid records from being inserted or updated.

Additional tests were conducted to verify that valid database operations succeeded and invalid operations were rejected.
